# Solo 视频生成工具 — 需求及设计文档

## 一、项目概述

Solo 视频生成工具是一个基于 AI 大模型的视频生成响应式 Web 工具。用户输入创意（诗词、故事、意境描述等），工具自动完成剧本生成、分镜脚本生成、角色提取、角色图生成、首帧图生成、视频生成的全流程，最终产出完整的微短剧视频。

### 技术栈

| 层级 | 技术 |
|------|------|
| 后端框架 | Python Flask 3.x |
| 前端 | 原生 HTML + CSS + JavaScript（无框架） |
| 大语言模型 | DeepSeek Chat API（剧本/分镜/角色/提示词生成） |
| 图片生成 | 火山引擎 Ark API（doubao-seedream-4-5-251128） |
| 视频生成 | ComfyUI（图生视频工作流 video_ltx2_3_i2v） |
| 日志 | 自研统一日志模块，同时输出控制台和 app.log 文件 |

### 外部依赖

- **DeepSeek API**：用于剧本生成、分镜脚本生成、角色提取、首帧图提示词生成

## 三、项目管理

### 3.1 项目编号与目录结构

每个创意项目分配唯一编号（P001, P002, ...），在 `solo/projects/` 下创建独立子目录。所有项目相关文件（创意、剧本、分镜、角色、图片、视频）均存放在该子目录中，实现数据隔离。

### 3.2 项目索引文件

`projects.json` 位于 `solo/` 目录下，维护所有项目的元数据：

```json
[
  {
    "id": "P001",
    "name": "项目名称",
    "creative_preview": "创意内容前20字",
    "created_at": "2026-06-03 12:00:00",
    "updated_at": "2026-06-03 12:30:00"
  }
]
```

### 3.3 项目管理 API

| 方法 | 路由 | 说明 |
|------|------|------|
| GET | `/api/projects/list` | 获取所有项目列表和当前活跃项目ID |
| POST | `/api/projects/create` | 创建新项目（自动编号，创建目录，保存创意和选项） |
| POST | `/api/projects/load` | 加载指定项目为当前活跃项目 |

### 3.4 前端项目管理

- 创意页面底部显示**历史项目列表**，每条显示：项目编号 + 创意前20字 + 更新时间
- 当前活跃项目高亮显示，顶部显示"当前项目：P001"
- 点击历史项目可切换，自动加载该项目的所有数据
- "新建项目"按钮清空表单并重置为未选项目状态
- 首次保存创意或生成剧本时，自动创建项目（无需手动创建）

## 四、页面功能详解

### 4.1 创意页面（Tab 1）

**功能**：用户输入创意内容，选择剧本生成方式和画幅比例。

**输入项**：
- 创意文本（textarea，支持多行）
- 剧本生成选项（3选1 radio）：
  - 选项一：小故事（情感类）— 以人性为底层内核，改编成触达人心的微剧小故事
  - 选项二：四联故事（情感类）— 选四首诗词，改编成高反差有网感的微剧小故事
  - 选项三：穿梭机（风景类）— 无人机POV视角，构建宏大场景和行动轨迹
- 画幅比例（2选1）：横板 16:9 / 竖版 9:16

**操作按钮**：
- **1. 保存创意**：保存创意和选项到当前项目目录
- **2. 保存创意并生成剧本**：保存后自动调用 DeepSeek 生成剧本，完成后自动跳转到剧本页面

**API 接口**：
- `GET /api/creative/load` — 加载当前项目的创意和选项
- `POST /api/creative/save` — 保存创意和选项

**数据文件**：
- `{项目目录}/创意.md` — 创意文本
- `{项目目录}/选项.json` — 选项配置（option_id、option_name、aspect_ratio）

---

### 4.2 剧本页面（Tab 2）

**功能**：展示和编辑 AI 生成的剧本。

**操作按钮**：
- **3. 重新生成剧本**：重新调用 DeepSeek 生成剧本
- **4. 保存剧本**：手动保存编辑后的剧本
- **5. 生成分镜**：基于当前剧本生成分镜脚本，完成后自动跳转到分镜页面

**API 接口**：
- `GET /api/script/load` — 加载当前项目的剧本
- `POST /api/script/save` — 保存剧本
- `POST /api/script/generate` — 调用 DeepSeek 生成剧本

**数据文件**：
- `{项目目录}/剧本.md` — 剧本文本

**剧本生成逻辑**（[api_client.py](file:///d:/AAA/video-tools/suye-movie/solo/api_client.py)）：
- 根据选项ID选择对应的 system_prompt 和 user_prompt_template
- 将画幅比例和创意内容注入模板
- 调用 DeepSeek Chat API（temperature=0.7, max_tokens=8192）

---

### 4.3 分镜页面（Tab 3）

**功能**：展示分镜脚本的 JSON 字段（分镜描述、视频提示词、首帧图提示词、尾帧图提示词、对话/旁白、角色列表等）。

**操作按钮**：
- **6. 重新生成分镜**：重新生成分镜脚本
- **7. 保存分镜**：确认保存分镜数据

**API 接口**：
- `GET /api/storyboard/load` — 加载当前项目的分镜脚本
- `POST /api/storyboard/save` — 保存分镜脚本
- `POST /api/storyboard/generate` — 调用 DeepSeek 生成分镜

**数据文件**：
- `{项目目录}/分镜.json` — 分镜脚本数组

**分镜 JSON 格式**：
```json
[
  {
    "group_id": "001",
    "scene_id": "001",
    "desc": "分镜描述",
    "duration": 10,
    "prompt_img_start": "首帧图提示词",
    "prompt_img_end": "尾帧图提示词",
    "prompt_video": "视频提示词（英文为主）",
    "narration": "分镜对话/旁白",
    "img_start": "首帧图路径",
    "img_end": "尾帧图路径",
    "video": "视频路径",
    "name_en_list": ["角色英文名"]
  }
]
```

**分镜提示词规范**（详见设计文档原始内容）：
- 通用结构：画幅比例 + 整体风格 + 镜头机位 + 运镜方式 + 场景环境 + 完整人物外貌+服饰+神态 + 肢体动作+表情细节 + 光影色调 + 画质细节 + 约束限定
- 分段时序写法：视觉描述使用英文，时间标记和人物说话内容使用中文（如 `0-3秒: [英文内容]`）
- 前缀统一固定：`{aspect_ratio}，电影级超写实，8K超清`
- 末尾统一加画质约束：`面部稳定无变形，动作流畅，画面无闪烁崩坏，有音效，无配乐，无字幕`

**角色年龄区分**：同一角色如有不同年龄段，使用后缀区分：`_young`（年轻）、`_old`（老年），中年/成年不加后缀

---

### 4.4 角色页面（Tab 4）

**功能**：提取角色并生成角色定型参考图。

**操作按钮**：
- **8. 提取角色**：从分镜脚本中提取角色，生成角色形象提示词
- **9. 生成角色图**：根据角色提示词调用 Seedream 生成角色图

**API 接口**：
- `GET /api/character/load` — 加载当前项目的角色列表
- `POST /api/character/extract` — 调用 DeepSeek 从分镜中提取角色
- `POST /api/character/generate-images` — 调用 Seedream 生成角色图

**数据文件**：
- `{项目目录}/角色.json` — 角色数组
- `{项目目录}/角色/char_{id}.png` — 角色图片

**角色 JSON 格式**：
```json
[
  {
    "id": "001",
    "name_cn": "角色中文名",
    "name_en": "角色英文名",
    "prompt": "角色形象提示词（英文）",
    "img": "角色图路径"
  }
]
```

**角色提示词设计**：面部特写 + 全身三视图组合（左侧超大面部特写，右侧正面/侧面/背面全身照），纯白背景，用作角色定型参考图。

**角色图生成流程**：
1. 遍历角色列表，为每个角色构造 prompt（追加 `aspect ratio {aspect_ratio}` 前缀）
2. 调用 Seedream API（doubao-seedream-4-5-251128），参数：`size=2K, watermark=false`
3. 下载生成的图片到 `{项目目录}/角色/char_{id}.png`
4. 更新角色 JSON 中的 img 字段

---

### 4.5 生图页面（Tab 5）

**功能**：生成分镜首帧图提示词、生成首帧图、生成视频。此页面合并了分镜首帧图和视频生成的全流程。

**操作按钮**：
- **10. 生成首帧图提示词**：根据分镜视频提示词（prompt_video），调用 DeepSeek 生成同风格的首帧图提示词
- **11. 生成首帧图**：根据首帧图提示词，调用 Seedream 生成首帧图（关联角色图作为参考）
- **12. 生成视频**：根据首帧图 + 视频提示词 + 时长，调用 ComfyUI 生成视频

**API 接口**：
- `POST /api/storyboard/generate-img-prompts` — 生成首帧图提示词
- `POST /api/storyboard/generate-images` — 生成首帧图
- `POST /api/storyboard/generate-videos` — 生成视频

**数据文件**：
- `{项目目录}/分镜/scene_{scene_id}.png` — 分镜首帧图
- `{项目目录}/视频/scene_{scene_id}.mp4` — 分镜视频

**首帧图生成流程**：
1. 遍历分镜列表，对每条的 prompt_video 调用 DeepSeek 生成 prompt_img_start
2. 遍历分镜列表，构建角色名→角色图映射，匹配 name_en_list 获取参考图
3. 调用 Seedream 生成首帧图，保存到 `{项目目录}/分镜/`

**视频生成流程**：
1. 上传首帧图到 ComfyUI
2. 加载 `video_ltx2_3_i2v_api.json` 工作流
3. 修改工作流参数：输入图片、正面提示词、视频时长、输出前缀
4. 提交到 ComfyUI 队列，轮询等待完成（超时 1800s）
5. 从 ComfyUI 输出目录复制视频到 `{项目目录}/视频/`

**页面功能**：
- 每个分镜显示：首帧图提示词、视频提示词、角色列表、首帧图预览、视频预览
- 首帧图横排预览：所有已生成首帧图的分镜横向排列
- 视频横排预览：所有已生成视频的分镜横向排列
- "打开文件位置"按钮：在文件资源管理器中定位文件

---

## 七、前端交互设计

### 7.1 Loading 遮罩

所有 API 请求自动触发 Loading 遮罩（全屏半透明遮罩 + 旋转动画），请求完成后自动消失。支持嵌套调用（通过计数器 tracking）。

### 7.2 状态消息

每个页面底部有状态消息区域，支持三种状态：
- `loading`（黄色）— 处理中
- `success`（绿色）— 操作成功
- `error`（红色）— 操作失败

### 7.3 媒体路径转换

前端通过 `toWebUrl()` 函数将本地绝对路径转为 Web 可访问 URL，支持缓存。分镜和角色数据加载时自动转换所有媒体路径。

### 7.4 响应式布局

CSS 采用暗色主题，支持桌面端和移动端自适应布局（`@media` 断点 768px / 480px）。

## 九、操作流程

完整的视频生成工作流，按编号顺序执行：

```
创意页面：
  1. 保存创意 ──→ 2. 保存创意并生成剧本
                              ↓
剧本页面：
  3. 重新生成剧本 ──→ 4. 保存剧本 ──→ 5. 生成分镜
                                              ↓
分镜页面：
  6. 重新生成分镜 ──→ 7. 保存分镜
                              ↓
角色页面：
  8. 提取角色 ──→ 9. 生成角色图
                              ↓
生图页面：
  10. 生成首帧图提示词 ──→ 11. 生成首帧图 ──→ 12. 生成视频
                                                      ↓
视频页面：
  13. 刷新视频列表
```

**注意**：步骤 11、12 依赖步骤 8、9（角色图需先生成），步骤 10 需在 11 之前执行。
