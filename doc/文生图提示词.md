# 七、在 ComfyUI 里的最佳使用方法
1. **正向提示词**：
    - 前 30%：画质、光影、构图
    - 中 40%：主体（人物/场景）
    - 后 30%：风格、色彩、细节
2. **负向提示词**：
    - 统一放在一个 **CLIP Text Encode** 里
    - 权重默认 1.0 即可
3. **权重技巧**
    - `(word:1.2)` 加强
    - `(word:0.8)` 减弱
