这是一个视频生成响应式工具，页面分为创意页面、剧本页面、分镜页面、角色页面、视频页面。用户在创意页面输入创意，选择剧本生成选项，工具根据创意和选项，生成剧本，分镜，角色。用户可以在分镜页面查看分镜脚本，可以在角色页面查看角色提示词。用户可以在视频页面查看生成的视频。

# 创意页面
用户输入一个创意，比如一首诗词，一个故事等，工具提供剧本生成选项给用户选择，保存用户输入的创意到 创意.md 文件
## 选项1. 小故事（情感类）
    剧本提示词：以人性为底层内核，以情绪表达为叙事骨架，把诗句改编成一个触达人心的微剧小故事
## 选项2. 四联故事（情感类）
    剧本提示词：以人性为底层内核，以情绪表达为叙事骨架，选同一意境或感受或思想内核的四首著名诗词，改编成一个高反差有网感的微剧小故事，故事融入时代背景（可以用旁白），结合作者的亲身经历，并读出诗词最有代表性的名句。最后在情绪共振中收尾。
## 选项3. 穿梭机（风景类）
    剧本提示词：用无人机穿梭机的POV第一视角来详细构建出诗句表达美景的详细描述，提取主角人物，能表现出主角在宏大的场景中的行动轨迹和情感变化。

# 剧本页面
根据用户的创意，和选择的剧本提示词，调用deepseek api，生成剧本，保存到 剧本.md 文件

# 分镜页面
根据剧本，使用下面的分镜提示词，调用deepseek api，生成分镜脚本，保存到 分镜.json 文件的prompt_video字段；
把分镜时长写入 分镜.json 文件的duration字段；
并把分镜中的角色英文名称保存到name_en_list字段列表中，同一个角色的英文名称只能出现一次。

## 分镜提示词：
用以下规则对剧本进行详细分镜：
一、通用结构（必按顺序写，算法识别度最高）
画幅比例 + 整体风格 + 镜头机位 + 运镜方式 + 场景环境 + 完整人物外貌+服饰+神态 + 肢体动作+表情细节 + 光影色调 + 画质细节 + 约束限定。
1. 100%尊重原文：所有对话、剧情、人设、场景均来自原文，不新增、不删减、不魔改、不原创解读。
2. 分镜按空间，动作，情绪，结果来描述，长描述分层，避免冗长堆砌
3. 人物样貌、发型、衣着、神态每镜完整写入，杜绝形象跑偏，人物形象要适配时代背景
4. 动作写细微具象动态，不写抽象情绪词
5. 负面约束后置：人物面部不变形、肢体无扭曲、动作顺滑、无闪烁崩坏、画面稳定
6. 禁止出现代词他/她或参考某一分镜的描述
7. 列出场景，分镜编号，标题，时长

二、分段时序提示词规范写法（必须严格遵守）:
语言规范：除了“时间标记（如 0-3秒）”和“人物说话内容（如 女子中文说：你好）”使用中文外，其余所有视觉描述、技术参数、运镜及环境描述必须全部使用英文提示词。
分秒控制：分镜内必须使用 0-3秒，[英文内容] 的格式来划分镜头切换和动作流。
对话逻辑：必须按照时间顺序描述对话，格式为：某某人物说：[内容]。
时序对齐：确保动作、运镜、对话的时间轴（0-X秒）在逻辑上完全匹配。
场景拆分：同一场景的分镜合理分配，最长约15秒的分镜提示词中，时间区间的秒数是按剧本内容动态调整规划的，不是固定值，总时长略超或略短都是允许的。
分镜15s示例：16:9，电影级超写实，8K超清，【镜头机位】，整体固定场景，【人物完整外貌+服饰定型描述】，整体光影色调，0-3秒:【起始状态、初始运镜】；4-10秒:【中段肢体动作、神态转变】；11-15秒:【收尾姿态、画面定格效果】

基础分段书写规则：
1. 前缀统一固定：16:9，电影级超写实，8K超清
2. 先写明机位、时空、整体场景、人物固定样貌服饰（整镜不变形象只写一次）
3. 按时间节点拆分动作、神态、运镜变化
4. 保留画幅、风格、镜头、运镜、人物、场景、动作、光影、防崩坏约束，同画面内按时段拆分动态变化，保证人物形象全程统一；
5. 末尾统一加画质约束：面部稳定无变形，动作流畅，画面无闪烁崩坏，有音效，无配乐，无字幕

三、避坑优化技巧（提升出片成功率）
1. 人物优先原则：人脸、服饰放在场景动作前写，AI优先锁定人物形象，减少换脸、穿搭错乱
2. 动作描写要"轻"：古风历史镜头少写大幅度蹦跳奔跑，多用：缓步、伫立、俯身、抬手、凝望、轻声吟诵，适配模型动作逻辑
3. 时长对应运镜：
    1. 短镜头：固定定镜、慢推，少大幅度晃动运镜；
    2. 长镜头：平移、环绕、拉远，增加轻微空间移动

# 角色页面
用 角色提取prompt，从分镜脚本中提取角色，保存到 角色.json 文件的prompt字段；

## 角色json格式：
{
    "id": "001", // 角色id
    "name_cn": "", // 角色名称中文
    "name_en": "", // 角色名称英文版本
    "prompt": "", // 角色提示词
    "img": "" // 角色图片
}

### 角色提取prompt：
    从上面分镜脚本中提取角色形象的提示词，分别为每个人物面部特写搭配全身三视图组合画面，画面左侧放置超大尺寸人物面部特写，右侧依次排布正面全身照、侧面全身照、背面全身照，所有内容整合在同一画幅内；严格复刻人物五官样貌、脸型轮廓、发型发色、身形比例、身高体态；完整还原全套服饰版型、色彩纹样、配饰穿戴、衣料褶皱细节；统一人物肤色、神态气质、画风光影。画面平铺排版，采用纯白色背景，严格对齐人物人体比例，杜绝透视畸变问题，各视图之间间距均匀规整，细节高度一致，用作角色定型参考图。

## 角色图生成
    遍历 角色.json 文件，根据 prompt 字段，调用火山seedance2.0模型api，生成角色图，保存到角色子目录下，完整图片路径保存到 角色.json 文件的img 字段；

# 分镜首帧图提示词
    根据 分镜.json 文件的 prompt_video 字段，使用分镜首帧图生成提示词，调用deepseek api，生成分镜首帧图片，保存到 分镜.json 文件的prompt_img_start 字段；

## 分镜首帧图生成提示词：
    请根据分镜视频提示词，生成同风格同比例的分镜首帧图片的提示词。

# 分镜首帧图生成
    遍历 分镜.json 文件，根据提示词（prompt_img_start 字段）和参考角色图（循环name_en_list字段中的角色名称，到 角色.json 文件中找对应的name_en字段，找到则获取对应的img字段值，这是角色图的本地完整路径），调用火山seedance2.0模型api，生成分镜首帧图片；保存到分镜子目录下，完整图片路径保存到 分镜.json 文件的img_start 字段

## 分镜页面增加分镜首帧图横排的预览功能
    分镜页面增加分镜首帧图横排的预览功能，用户可以在分镜页面查看分镜首帧图的横排预览，确认无误后再生成分镜视频。

# 分镜视频生成页面
    接入comfyui的D:\AAA\video-tools\suye-movie\code\video_ltx2_3_i2v_api.json图生视频工作流；
    传入 分镜.json 文件的图生视频提示词（prompt_video 字段），传入参考首帧图（img_start 字段），传入分镜时长（duration 字段），调用comfyui模型，生成分镜视频，保存到分镜子目录下，视频完整路径保存到 分镜.json 文件的video 字段；

## 分镜页面增加分镜视频横排的预览功能
    分镜页面增加分镜视频横排的预览功能，用户可以在分镜页面查看分镜视频的横排预览。
